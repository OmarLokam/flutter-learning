## 📱 Tasks & Projects (Chronological Order)

### 1. 📱 Meals App (`Meals_App`)
* **Description:** A dynamically structured UI application designed to display various meal categories and detailed recipes efficiently.
* **Key Features Implemented:**
  * **Clean Directory Architecture:** Organized layout with strict separation of concerns into dedicated layers (models, screens, widgets).
  * **Reusable Components:** Implemented custom widgets (like `CategoryItem`) to reduce redundancy and ensure modular, maintainable code.
  * **Custom UI & Theming:** Enhanced layouts using specific alignments, custom cards, and strict theme styling (e.g., `Colors.deepOrangeAccent` for structural background branding).
  * **Model-Driven UI:** Utilizing structured models (`CategoryModel`) to dynamically map and handle data properties including remote network images.

### 2. 🧮 Calculator App (`calculator_app`)
* **Description:** A functional and responsive calculator application designed to master layout design and state manipulation.
* **Key Features Implemented:**
  * **Grid Layout Construction:** Building a responsive layout with smooth alignment for user input and operations.
  * **Component Modularization:** Fully separated the button view into a custom, reusable `MathButton` widget with dynamic property mapping.
  * **Neumorphic UI Styling:** Enhanced the dark-themed user interface with layered `BoxShadow` offsets (`5, 5` and `-5, -5`) for an advanced visual depth.
  * **Robust Logical Validation:** Implemented precise calculation methods with error handling (using `double.tryParse`) to process expressions and catch exceptions like division by zero.

### 3. 🍽️ Restaurant App (`restaurant_app`)
* **Description:** An advanced restaurant application that levels up the initial Meals App with professional data filtering and structured cross-platform architectures.
* **Key Features Implemented:**
  * **Category-Based Item Filtering:** Implemented efficient loop-based logic to filter and dynamically render specific meals belonging to the selected category ID.
  * **Advanced Reusable Architecture:** Cleanly isolated individual meal previews into a highly customizable and detailed `MealItem` widget.
  * **Conditional UI Rendering:** Gracefully handles empty states by switching layouts dynamically if no matching items are found.
